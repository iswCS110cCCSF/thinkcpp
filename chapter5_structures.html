    Section 5.1 Structures

    So far, variables have usually represented individual pieces of data. Sometimes several values naturally belong together. For example, a point on a coordinate plane has both an x-coordinate and a y-coordinate.
    🔗
    We could store those values in separate variables:
    🔗
    double x = 3.0;
double y = 4.0;
    However, the two values describe one conceptual object: a point. C++ provides structures so related values can be grouped into a single user-defined type.
    🔗

    Subsection 5.1.1 Defining a Structure

    A structure is defined using the struct keyword. The following definition creates a new type named Point:
    🔗
    struct Point {
    double x;
    double y;
};
    The variables declared inside the structure are called data members. A Point has two data members: x and y.
    🔗
    Notice the semicolon after the closing brace. A structure definition must end with a semicolon.
    🔗
    Defining Point creates a new type. It does not yet create a particular point object.
    🔗
    We can think of the structure definition as describing the layout of every Point object:
    🔗
    Point
+----------------+
| x : double     |
| y : double     |
+----------------+
    A structure type must be defined before it is used to create objects or in function declarations. In the complete single-file programs in this book, structure definitions therefore appear near the top of the file, after the #include directives and before function declarations and main.
    🔗
    🔗

    Subsection 5.1.2 Creating Structure Objects

    Once a structure type has been defined, we can create objects of that type in much the same way that we create variables of built-in types.
    🔗
    Point location;
    Here, location is an object whose type is Point. It contains its own x and y data members.
    🔗
    Fundamental-type data members should not be left uninitialized. One safe way to create a structure object is to use empty braces:
    🔗
    Point origin{};
    With this form, the numeric data members are value-initialized. For this Point, both x and y become 0.0.
    🔗
    origin
+----------------+
| x : 0.0        |
| y : 0.0        |
+----------------+
    Here is the complete program.
    🔗
    #include <iostream>

struct Point {
    double x;
    double y;
};

int main() {
    Point origin{};;

    return 0;
}
    🔗

    Subsection 5.1.3 Aggregate Initialization

    We can also provide initial values when an object is created.
    🔗
    Point location{3.0, 4.0};
    The values are assigned to the data members in the order in which the members appear in the structure definition.
    🔗
    location
+----------------+
| x : 3.0        |
| y : 4.0        |
+----------------+
    This form is called aggregate initialization.
    🔗
    For another structure:
    🔗
    struct Rectangle {
    double length;
    double width;
};
    the statement:
    🔗
    Rectangle room{12.0, 8.0};
    initializes length to 12.0 and width to 8.0.
    🔗
    room
+------------------+
| length : 12.0    |
| width  : 8.0     |
+------------------+
    🔗

    Subsection 5.1.4 Accessing Data Members

    Use the dot operator, ., to access a data member of a structure object.
    🔗
    Point location{3.0, 4.0};

std::cout << location.x << '\n';
std::cout << location.y << '\n';
    The expression location.x means the x data member belonging to the object named location.
    🔗
    Similarly:
    🔗
    Rectangle room{12.0, 8.0};

std::cout << room.length << '\n';
std::cout << room.width << '\n';
    Data members can also be changed using the dot operator:
    🔗
    room.length = 15.0;
room.width = 10.0;
    After these assignments, the state of room is:
    🔗
    room
+------------------+
| length : 15.0    |
| width  : 10.0    |
+------------------+
    🔗

    Subsection 5.1.5 Each Object Has Its Own Data

    Different objects of the same structure type have their own copies of the data members.
    🔗
    Point first{2.0, 5.0};
Point second{8.0, 1.0};
    These are two separate Point objects:
    🔗
    first                     second
+--------------+          +--------------+
| x : 2.0      |          | x : 8.0      |
| y : 5.0      |          | y : 1.0      |
+--------------+          +--------------+
    Changing first.x does not change second.x.
    🔗
    first.x = 10.0;
    Now the objects contain:
    🔗
    first                     second
+--------------+          +--------------+
| x : 10.0     |          | x : 8.0      |
| y : 5.0      |          | y : 1.0      |
+--------------+          +--------------+
    🔗

    Subsection 5.1.6 Copying Structure Objects

    An object of a structure type can be copied to another object of the same type.
    🔗
    Point first{3.0, 4.0};
Point second = first;
    The values of first’s data members are copied into second.
    🔗
    first                     second
+--------------+          +--------------+
| x : 3.0      |          | x : 3.0      |
| y : 4.0      |          | y : 4.0      |
+--------------+          +--------------+
    The objects are still independent. Changing one object afterward does not automatically change the other.
    🔗
    second.x = 9.0;
    Now:
    🔗
    first                     second
+--------------+          +--------------+
| x : 3.0      |          | x : 9.0      |
| y : 4.0      |          | y : 4.0      |
+--------------+          +--------------+
    This copying behavior will become important in the next section when we pass structure objects to functions.
    🔗
    🔗

    Subsection 5.1.8 Check Your Understanding

    Checkpoint 5.1.1.

    In the following structure definition, which names are data members?
    🔗
    struct Temperature {
    double high;
    double low;
};
    • Temperature only
    • Temperature is the name of the structure type.
    • high and low
    • The variables declared inside the structure are its data members.
    • double and Temperature
    • double is a type, and Temperature is the user-defined structure type.
    🔗

    Checkpoint 5.1.2.

    Given:
    🔗
    Point location{7.0, 2.0};
    which expression accesses the y data member of location?
    🔗
    • Point.y
    • Use the object name before the dot operator.
    • location-y
    • Structure members are accessed using the dot operator.
    • location.y
    • The dot operator accesses a data member belonging to an object.
    • y.location
    • The object name appears before the dot, followed by the member name.
    🔗

    Checkpoint 5.1.3.

    Consider:
    🔗
    Point first{3.0, 4.0};
Point second = first;

second.x = 10.0;
    What is the value of first.x after these statements?
    🔗
    • 3.0
    • second received a copy. Changing second.x does not change first.x.
    • 4.0
    • 4.0 is the value of first.y.
    • 10.0
    • The assignment changes second.x, not first.x.
    🔗

    Checkpoint 5.1.4.

    Which structure definition is written correctly?
    🔗
    • struct Robot {
    int battery_level;
    double speed;
}
    • A structure definition must end with a semicolon after the closing brace.
    • struct Robot {
    int battery_level;
    double speed;
};
    • The data members are declared inside the braces, and the structure definition ends with a semicolon.
    • struct Robot;
{
    int battery_level;
    double speed;
}
    • The opening brace belongs immediately after the structure name in this definition.
    🔗
