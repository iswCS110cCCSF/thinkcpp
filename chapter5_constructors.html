    Section 5.6 Constructors

    In the previous section, a Rectangle object first received default values and then used set_dimensions to establish useful dimensions.
    🔗
    Rectangle room;
room.set_dimensions(12.0, 8.0);
    It would be better if an object could receive its intended starting state at the moment it is created.
    🔗
    C++ provides a special member function for this purpose: a constructor.
    🔗

    Subsection 5.6.1 What Is a Constructor?

    A constructor is a special member function that is called automatically when an object is created.
    🔗
    A constructor has the same name as its class and has no return type.
    🔗
    class Rectangle {
public:
    Rectangle(double initial_length, double initial_width);

private:
    double length;
    double width;
};
    The declaration
    🔗
    Rectangle(double initial_length, double initial_width);
    declares a constructor for Rectangle. Notice that there is no return type, not even void.
    🔗
    When an object is created with matching arguments, C++ calls the constructor automatically:
    🔗
    Rectangle room{12.0, 8.0};
    Here, 12.0 and 8.0 are passed to the constructor as initial_length and initial_width.
    🔗
    🔗

    Subsection 5.6.2 Defining a Constructor

    Like other member functions, a constructor can be declared inside the class and defined later.
    🔗
    class Rectangle {
public:
    Rectangle(double initial_length, double initial_width);

private:
    double length;
    double width;
};
    The definition uses the scope resolution operator:
    🔗
    Rectangle::Rectangle(double initial_length, double initial_width) {
    length = initial_length;
    width = initial_width;
}
    The name appears twice:
    🔗
    Rectangle::Rectangle
    The first Rectangle identifies the class whose member is being defined. The second Rectangle is the name of the constructor.
    🔗
    A constructor does not return an object with a return statement. C++ creates the object and then runs the constructor to initialize it.
    🔗
    🔗

    Subsection 5.6.3 Member Initializer Lists

    C++ provides a preferred syntax for initializing data members in a constructor: a member initializer list.
    🔗
    Rectangle::Rectangle(double initial_length, double initial_width)
    : length(initial_length), width(initial_width) {
}
    The initializer list appears after the constructor’s parameter list and before the constructor body.
    🔗
    In this example:
    🔗
    length(initial_length)
width(initial_width)
    initialize the data members length and width from the constructor parameters.
    🔗
    For straightforward member initialization, prefer an initializer list rather than first creating the members and then assigning values inside the constructor body.
    🔗
    The parameter names initial_length and initial_width also make it clear which names are parameters and which names are data members.
    🔗
    🔗

    Subsection 5.6.4 Calling a Constructor

    We can create a Rectangle and pass constructor arguments using braces:
    🔗
    Rectangle room{12.0, 8.0};
Rectangle table{6.0, 3.0};
    Each statement creates a separate object and invokes the constructor for that object.
    🔗
    Parentheses can also be used for this kind of construction:
    🔗
    Rectangle room(12.0, 8.0);
    In this book, we will generally prefer brace initialization:
    🔗
    Rectangle room{12.0, 8.0};
    Earlier, braces were used to initialize simple structures directly. Once a class provides constructors, braces can also be used to select and call a matching constructor.
    🔗
    🔗

    Subsection 5.6.5 A Default Constructor

    A constructor that can be called with no arguments is called a default constructor.
    🔗
    class Rectangle {
public:
    Rectangle();
    Rectangle(double initial_length, double initial_width);

private:
    double length;
    double width;
};
    We can define the default constructor so that a newly created rectangle begins as a 1-by-1 rectangle:
    🔗
    Rectangle::Rectangle()
    : length(1.0), width(1.0) {
}
    Now this declaration calls the default constructor:
    🔗
    Rectangle unit_square;
    Braces may also be written explicitly:
    🔗
    Rectangle unit_square{};
    Both forms create a Rectangle using the no-argument constructor.
    🔗
    🔗

    Subsection 5.6.6 Constructor Overloading

    A class can have more than one constructor as long as the parameter lists allow C++ to determine which constructor to call.
    🔗
    class Rectangle {
public:
    Rectangle();
    Rectangle(double initial_length, double initial_width);

private:
    double length;
    double width;
};
    These two constructors have the same name but different parameter lists. This is called constructor overloading.
    🔗
    The arguments used when an object is created determine which constructor is selected:
    🔗
    Rectangle unit_square;        // calls Rectangle()
Rectangle room{12.0, 8.0};    // calls Rectangle(double, double)
    Constructor overloading is one example of the more general idea of function overloading. We will study function overloading in more detail later in the book. For now, the important idea is that a class may provide more than one sensible way to create an object.
    🔗
    🔗

    Subsection 5.6.7 Constructors and Object State

    A constructor gives a class control over the state an object has when it first comes into existence.
    🔗
    For example, the default constructor below creates a sensible 1-by-1 rectangle:
    🔗
    Rectangle::Rectangle()
    : length(1.0), width(1.0) {
}
    For the constructor that receives dimensions, we can also decide what should happen if the requested values are not valid for our model.
    🔗
    Rectangle::Rectangle(double initial_length, double initial_width)
    : length(1.0), width(1.0) {
    if (initial_length > 0.0 && initial_width > 0.0) {
        length = initial_length;
        width = initial_width;
    }
}
    This version begins with a valid 1-by-1 rectangle. If both requested dimensions are positive, the constructor replaces those defaults with the requested values. Otherwise, the object remains 1 by 1.
    🔗
    This is one possible design policy. Different classes may choose different policies for invalid construction requests. We will return to those design decisions when we discuss an object’s interface and behavior.
    🔗
    🔗

    Subsection 5.6.9 Check Your Understanding

    Checkpoint 5.6.1.

    Which declaration correctly declares a constructor for a class named Book?
    🔗
    • void Book();
    • A constructor has no return type, not even void.
    • Book();
    • A constructor has the same name as the class and no return type.
    • book();
    • Constructor names must match the class name exactly.
    • Book Book();
    • A constructor does not specify a return type.
    🔗

    Checkpoint 5.6.2.

    Given these constructor declarations, which constructor is called by Rectangle room{12.0, 8.0};?
    🔗
    Rectangle();
Rectangle(double initial_length, double initial_width);
    • Rectangle()
    • The no-argument constructor does not match the two arguments supplied when room is created.
    • Rectangle(double initial_length, double initial_width)
    • The two supplied double values match the two-parameter constructor.
    • Both constructors
    • One matching constructor is selected for the construction.
    🔗

    Checkpoint 5.6.3.

    What is the purpose of the initializer list in this constructor?
    🔗
    Book::Book(const std::string& initial_title, int initial_year)
    : title(initial_title), year(initial_year) {
}
    • It initializes the data members from the constructor arguments.
    • The initializer list initializes title and year as the object is constructed.
    • It declares two new local variables named title and year.
    • title and year are data members of the object.
    • It returns the completed Book object.
    • Constructors do not return objects with a return statement.
    🔗
